# 0001 · 确认通知后才清除账户

**状态：**已采纳。

**背景：**云端管理员需要回收长期不用的账户，但用户应有机会取回数据。直接删除最快，从管理员确认时计时则可能在邮件未交接的情况下清除。

**决定：**单个和批量操作共用预览、通知与清除流程。只有 SMTP 接受唯一收件人且本地记录成功，才起算 168 小时；缺少有效邮箱、拒收或交接结果未知时不清除。截止前保留原权限并允许撤销，登录不会重置期限。所有管理员、默认账户和操作者本人受保护。

**影响：**截止时先阻止访问和中止备份，再等待在途数据操作结束。任务和清除过程在持久卷上恢复。SMTP 与本地磁盘不能组成同一个事务，重启后发送中断记录只能由管理员核对并重试，不反推截止。生产部署仅运行一个应用进程；退回旧版前要核对在途任务，不能带着有效任务直接恢复旧版的即时删除功能。
