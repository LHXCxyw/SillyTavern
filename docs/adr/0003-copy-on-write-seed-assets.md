# 0003 · 以可选写时复制播种默认资源

**状态：**提案，待用户确认。

**背景：**账号开户时会把发行版默认素材物化到每个用户目录。当前跟踪的种子为每账号 191 个文件、16,134,731 字节；按独立复制估算，300 个空白账号的种子内容约 4.51 GiB。背景图和角色素材占种子字节的 98.79%。上游功能依赖每用户可枚举、可修改的真实路径；硬链接会共享 inode，现有备份与清除会拒绝多硬链接文件，且修改可能污染其他用户。OverlayFS 的 copy-up、whiteout、备份视图和目录清除也不等价于当前语义。

**决定：**保持每用户原路径、普通独立文件、列表及 ZIP/清除语义。可在 `dataRoot` 中保存按上游版本及内容哈希识别的只读种子快照。Node 的 `COPYFILE_FICLONE` 会尝试 CoW，能力不支持时可回退普通复制，但 API 不报告单个文件是否克隆；强制模式会暴露失败，但跨平台错误识别和 fallback 由应用负责。故部署不得把每次复制成功当成已共享磁盘块；用同一卷的能力探针与隔离 300 账号物理块实测判断支持程度。具体使用非强制模式或经验证的强制探针+逐文件模式仍待确认。不以硬链接替代。播种和补种只处理既有索引判定应存在、且目标尚不存在的文件；不覆盖用户修改、不因共享层重新出现用户已删除的已登记资源。无人工操作不得清理仍被用户目录引用的旧快照。各模式的跨平台行为、共享块计量和异常语义须以 Windows/Linux 测试证实。

**存量迁移：**仅在停服后，按 SQLite 账户列表和版本化 manifest 逐一访问种子中已知的相对路径；不遍历、复制或打包完整用户目录。只有内容哈希完全匹配当前/保留的发行种子、目标是普通单链接文件、目标 volume 已实测强制 CoW 克隆成功、且 manifest 对应的删除账本允许时，才将文件原子替换成独立 CoW 克隆。不能强制克隆时跳过该项，不回退为普通大文件复制；用户修改、哈希不匹配、既有克隆/硬链接/符号链接或来源不明的文件保持原样。dry-run 输出每账号候选字节、预期释放块数与跳过原因。不可把 CoW 当回退副本；事务失败时从仍保留的精确版本种子母版逐文件恢复本次修改项。运维级全盘灾备应放到其他设备，不要求在已满的同一数据盘创建全量快照。

**影响：**所有文件仍保留用户路径，扩展、原有内容接口、用户 ZIP 和物理清除不读取 OverlayFS 视图。CoW 会在用户修改文件时增加独立数据块；新开户即使不支持 CoW 仍回退普通复制。存量迁移更严格：空间紧张时绝不普通复制每个候选文件；强制 clone 能力不满足就跳过该账户/卷，不产生改动。新开户放行指标是在经确认支持 CoW 的隔离数据卷上，为 300 个合成空白账号创建默认种子，与普通复制对照，种子数据块新增量至少降低 90%；同时验证每个文件内容和用户备份条目与普通复制一致。未达到指标时，不称为磁盘优化完成。已有用户种子迁移通过资源级 journal 回退；灾难恢复全盘快照另存于其他设备，而不是在满载 dataRoot 同卷复制。
